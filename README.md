# DiveNotebook updates

This public repository hosts the static update-metadata endpoint for DiveNotebook through GitHub Pages. Android application packages are hosted separately on Expo.

## Publishing scope

Only reviewed public release metadata and this small static site belong here. Never commit inspection records, reports, photos, application source code, APK files, passwords, credentials, private signing keys, or backups.

Signed update metadata will be published after the corresponding release has been verified. No update manifest is included in this initial scaffold.

## Hosting

GitHub Pages serves the root of the `main` branch. The site is static and does not collect inspection data or accept uploads.
